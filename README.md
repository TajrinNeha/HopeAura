# HopeAura — Disaster Relief E-Commerce System

HopeAura is a professional frontend project built from the submitted project proposal. It focuses only on the proposed disaster relief features: SOS request, relief item ordering, donation management, volunteer coordination, NGO/admin dashboard, live tracking, shelter finder, analytics, and responsive design.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage for frontend demo data
- SVG assets designed inside the project

## Project Highlights

- Human-centered emergency homepage
- SOS request form with GPS support
- Relief item ordering basket
- Donation pledge and transparent progress board
- Volunteer registration and priority task acceptance
- Shelter finder with district filter and capacity view
- Request tracking using unique request IDs
- NGO/Admin dashboard with status updates and analytics
- Fully responsive layout for mobile, tablet, and desktop

## How to Run

1. Extract the ZIP file.
2. Open the `HopeAura_Project` folder.
3. Double-click `index.html` to open it in a browser.
4. No server, database, or internet connection is required for the demo.
